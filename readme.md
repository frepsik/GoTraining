## Симуляция работы метеоцентра

Мы реализуем систему, имитирующую работу метеоцентра.

### Описание

Метеоцентр собирает показания с датчиков трёх типов:

1. **Датчики давления** — анализируют атмосферное давление  
2. **Датчики влажности** — анализируют влажность воздуха  
3. **Сейсмические датчики** — анализируют сейсмическую активность  

### Требования к симуляции

- Каждый тип датчиков должен работать в отдельных горутинах  
- На **каждый датчик** создаётся **отдельная горутина**  
- Количество датчиков каждого типа может быть произвольным  
- Каждый датчик передаёт:
  - измеренные данные
  - координаты точки, где было сделано измерение  
- Данные отправляются **каждую секунду**

### Требования к `main`-горутины

Главная горутина должна:

1. Контролировать работу всех датчиков  
2. Иметь возможность **в любой момент остановить работу датчиков определённого типа**  
3. Собирать и обрабатывать данные от всех датчиков  

### Дополнительные условия

При реализации необходимо учитывать:

- корректную работу с горутинами  
- безопасное взаимодействие между ними (каналы, синхронизация)  
- отсутствие утечек горутин  
- корректное завершение работы программы
